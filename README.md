# Nanoteqa · pradžios puslapio maketas (v4 „Spalvų kodas“)

Naujos Nanoteqa svetainės pradžios puslapio dizaino maketas. Svetainė bus kuriama su WordPress, WooCommerce ir Salient tema.

**Gyva peržiūra:** https://arvydastry.github.io/nanoteqa/

- Produktai, kainos, talpos, kontaktai ir pristatymo sąlygos paimti iš dabartinės nanoteqa.lt parduotuvės.
- Atsiliepimai pažymėti „Pavyzdys“ – bus pakeisti tikrais.
- Krepšelis veikia tik naršyklėje, formos duomenų nesiunčia, apmokėjimas neveikia.
- Fono video ir kai kurios nuotraukos – Pexels (nemokama licencija).
